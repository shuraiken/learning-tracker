# Prioritization

## Purpose

Choose which work to do next, once, and with explicit reasons.

---

## Frameworks

### RICE

Score = (Reach × Impact × Confidence) / Effort.

* **Reach** — how many people/actions are affected per time period.
* **Impact** — magnitude of effect per person.
* **Confidence** — how sure the numbers are.
* **Effort** — cost to build.

Compare RICE scores relative to one another. Calibrate to the same scale.

### WSJF

Weighted Shortest Job First for a queue.

Score = (Value + Time Criticality + Risk Reduction/Opportunity Enablement) / Job Size

Use for sequencing a flow of work rather than an absolute ranking.

### MoSCoW

Must / Should / Could / Won't

Use early to shape scope for a release or deliverable.

---

## Choosing a Framework

* Need an absolute, comparable ranking of many items → **RICE**.
* Sequencing a delivery pipeline and time-to-value matters → **WSJF**.
* Negotiating release scope with stakeholders → **MoSCoW**.

Explain *why* a framework fits rather than always defaulting to the same one.

## Effort vs. Value

Visualize effort (cost) against value.

Prefer work that is:

* High value, low effort (quick wins).
* Strategic high value, high effort only when the outcome demands it.

Avoid spending on:

* Low value regardless of effort.

State the assumption behind each estimate. Revise as new information emerges.
