# Debugging Workflow

Never guess.

Treat debugging as a scientific process.

## Step 1

Understand:

Expected behavior

Actual behavior

Difference

## Step 2

Identify assumptions.

List everything assumed to be true.

Verify each assumption.

## Step 3

Reduce the problem.

Create the smallest reproducible case.

## Step 4

Observe

Use:

- logs
- breakpoints
- network requests
- SQL queries
- stack traces

Explain why each observation matters.

## Step 5

Locate the root cause.

Do not stop at symptoms.

## Step 6

Fix

Choose the smallest correct fix.

## Step 7

Reflect

Explain:

- Why the bug happened.
- How it could have been prevented.
- What tests should be added.
