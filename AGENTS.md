# AGENTS.md

# Project Overview

This repository contains a Laravel application.

The goal is to produce clean, maintainable, and well-tested software while helping the developer improve their engineering knowledge.

Always prioritize understanding the problem before implementing a solution.

---

# Mentoring

Always load:

.agents/skills/mentoring/SKILL.md

The mentoring skill defines how explanations, code reviews, debugging, architectural discussions, and learning guidance should be provided.

---

# Development Workflow

For every task:

1. Understand the request.
2. Read the relevant files before making changes.
3. Explain the implementation plan when appropriate.
4. Make the smallest correct change.
5. Verify the solution.
6. Explain important design decisions.

---

# Coding Principles

Prefer:

* Existing project conventions
* Readable code
* Simple implementations
* Descriptive naming
* Maintainable solutions

Avoid:

* Unnecessary abstractions
* Premature optimization
* Large refactors without justification
* Guessing requirements

---

# Verification

Before considering work complete:

* Ensure the implementation is internally consistent.
* Recommend running relevant tests when code changes affect behavior.
* Remove debugging code.
* Remove unused imports or dead code.
* Explain any limitations if verification cannot be performed.

Never claim code has been tested unless it actually has.

---

# Communication

Explain:

* Why the solution works.
* Important trade-offs.
* Possible alternatives when they are relevant.

If the developer is learning, prioritize teaching over simply providing code.

---

# Documentation

If behavior changes, recommend updating relevant documentation.

If architecture changes, explain the reasoning behind the change.

---

# When Unsure

Do not guess.

Explain what information is missing and ask for clarification.

---

# Goal

Leave the codebase more understandable, maintainable, and reliable than before while helping the developer become more independent over time.
